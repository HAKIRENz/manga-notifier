# ระบบแจ้งเตือนการ์ตูนอัปเดต (ฟรี 24 ชม.)

GitHub Actions ตรวจเว็บทุก ~15 นาที → ส่งแจ้งเตือนเข้า Discord → จัดการรายการเรื่องผ่านหน้าเว็บ `index.html`

## ตั้งค่า (ทำครั้งเดียว ~10 นาที)

1. **Discord**: สร้างเซิร์ฟเวอร์ส่วนตัว → ตั้งค่าช่อง → Integrations → Webhooks → New Webhook → คัดลอก URL
2. **GitHub**: สร้าง repo ใหม่ชื่อ `manga-notifier` (public ก็ได้ ฟรีไม่จำกัดเวลารัน) แล้วอัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ `.github`)
3. repo → Settings → Secrets and variables → Actions → New secret
   ชื่อ `DISCORD_WEBHOOK_URL` ค่า = URL จากข้อ 1
4. repo → Settings → Pages → Source: Deploy from branch → `main` / root → จะได้ลิงก์หน้าจัดการ
5. สร้าง Token: GitHub → Settings → Developer settings → Fine-grained tokens → เลือกเฉพาะ repo นี้ →
   Permissions: **Contents: Read and write** และ **Actions: Read and write**
6. เปิดหน้าจัดการ → วาง `ชื่อผู้ใช้/manga-notifier` กับ token → เพิ่มเรื่องที่ต้องการได้เลย

## หมายเหตุ
- เรื่องที่เพิ่มใหม่จะจำตอนล่าสุดไว้เงียบ ๆ ก่อน ไม่แจ้งเตือนย้อนหลัง
- ใช้ได้กับเว็บส่วนใหญ่โดยอ่านลิงก์ตอนในหน้าเรื่อง; MangaDex ใช้ API ตรง ๆ
- เว็บที่มี Cloudflare/ต้องล็อกอิน/โหลดตอนด้วย JavaScript อาจอ่านไม่ได้ จะขึ้นข้อผิดพลาดในหน้าจัดการ และเตือนใน Discord หลังพลาด 6 ครั้งติดกัน
- GitHub จะปิด schedule ถ้า repo เงียบ 60 วัน ระบบจึง commit สถานะวันละครั้งให้อัตโนมัติ
- อย่าแชร์ token ให้ใคร

## ถ้าเว็บบล็อก (ทำไมถึงโดนบล็อก และแก้ยังไง)
สาเหตุหลักคือ IP ของ GitHub เป็น IP ดาต้าเซ็นเตอร์ ซึ่งเว็บที่ใช้ Cloudflare จำนวนมากบล็อกตั้งแต่แรก ระบบนี้จึงตรวจแบบเบา:
- แต่ละเรื่องตรวจทุก 30 นาที (แก้ต่อเรื่องได้โดยเพิ่มฟิลด์ `"interval": 60` ใน series.json)
- เว้นระยะสุ่ม 4-10 วินาทีระหว่างคำขอไปเว็บเดียวกัน และสลับลำดับเรื่องทุกรอบ
- ใช้ ETag/Last-Modified ถ้าหน้าไม่เปลี่ยนเว็บตอบ 304 แทบไม่เสียทรัพยากร
- ถ้าเจอ 403/429 จะพักเว็บนั้น 1→2→4→…→24 ชม. (เคารพ Retry-After) และแจ้งเตือนใน Discord ครั้งเดียว ไม่ยิงซ้ำ
- ใส่ลิงก์ RSS/Atom ของเว็บแทนลิงก์หน้าเรื่องได้ (เบาและไม่ค่อยโดนบล็อก)

ถ้าเว็บใดยังปฏิเสธอยู่ แนวทางที่เหลือ: (1) หาฟีด RSS ของเว็บนั้น (2) ย้ายไปอ่านจาก MangaDex หรือเว็บที่มี API (3) รัน check.py บนคอมหรือ Raspberry Pi ที่บ้านด้วย cron/Task Scheduler (IP บ้านไม่ถูกมองเป็นบอทเท่า แต่ต้องเปิดเครื่องทิ้งไว้) ระบบนี้ไม่ได้พยายามหลบ Cloudflare/captcha เพราะเปราะบางและเสี่ยงโดนแบนถาวร
