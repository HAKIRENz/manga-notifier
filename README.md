# Manga Watch v4 — ติดตามการ์ตูนตอนใหม่ + แจ้งเตือน Discord (ฟรี 24 ชม.)

```
Cloudflare Worker ── ทุก 5 นาที: มีเรื่องถึงเวลาตรวจไหม? ──► GitHub Actions (ตรวจเว็บ) ──► Discord
   ▲ ล็อกอิน/ยศ/API                                          │ เก็บสถานะใน branch "data"
หน้าเว็บ (GitHub Pages / แอป) ◄──────────────────────────────┘   (รอบสำรองของ GitHub ทุก ~30 นาที)
```

## อัปเดต v3 → v4 (ประมาณ 5 นาที)

### ขั้น A — อัปโหลดไฟล์ขึ้น GitHub
1. แตก zip → เปิด repo `manga-notifier` → **Add file → Upload files**
2. ลากไฟล์ทั้งหมดใน zip ลงไป (**รวมโฟลเดอร์ `.github` และ `worker`**) → Commit
   (zip นี้ไม่มี `series.json` / `state.json` / `subs.json` / `config.json` จึงไม่ทับข้อมูลเดิม)

### ขั้น B — อัปเดตโค้ด Worker
1. Cloudflare → **Workers & Pages** → เปิด `manga-watch-api` → **Edit code**
2. กด Ctrl+A ลบโค้ดเดิมทั้งหมด → วางเนื้อหาไฟล์ `worker/worker.js` ตัวใหม่ → **Deploy**

### ขั้น C — ตั้งนาฬิกาปลุกทุก 5 นาที (Cron Trigger) ⭐ ขั้นใหม่
1. ในหน้า Worker เดิม → แท็บ **Settings** → หัวข้อ **Trigger Events** → กด **+ Add**
2. เลือก **Cron Triggers**
3. เลือก **Every 5 minutes** (หรือพิมพ์ช่อง Cron ว่า `*/5 * * * *`) → กด **Add** / **Deploy**
4. รอ 5-10 นาที → หน้าเว็บ แท็บ **ระบบ** ช่อง “Cloudflare สั่งตรวจล่าสุด” ต้องขึ้นเวลา
   และใน GitHub → Actions จะเห็นรอบชื่อ **อัตโนมัติ (Cloudflare)**

> รอบ Cron ไม่เขียน KV และเรียก GitHub แค่ 3-5 ครั้งต่อรอบ → ไม่กินโควตาฟรีของ Cloudflare

### ขั้น D — (แนะนำ) ตั้งค่าในหน้าเว็บ
- แท็บ **ระบบ → 🚨 แจ้งเตือนเจ้าของ**: ใส่ Discord ID ของคุณ → บอทจะแท็กคุณเมื่อเว็บบล็อก/Token ใกล้หมด/Cloudflare หยุดทำงาน
- แท็บ **ระบบ → ⭐ ช่วงออกตอนหลัก**: ค่าเริ่มต้น 22:50–00:30 และ 04:50–06:30 (เวลาไทย) ตรวจทุก 5 นาที นอกช่วงทุก 6 ชม.

| ⏱ ทุก ๆ X ชม. (1/2/3/6/12/24) | ไม่รู้เวลาออก | 24 / 12 / 8 / 4 / 2 / 1 |

- 💤 เรื่องที่ไม่มีตอนใหม่เกิน 30 วัน ตรวจห่างลงเอง (ทุก 12 ชม. + ตอนเริ่มช่วงเฝ้า) ปิดได้รายเรื่อง
- เรื่องเดิมทั้งหมดย้ายไปโหมด ⭐ ให้อัตโนมัติ (เรื่องที่เคยตั้งเวลาเองจะเป็นโหมด 🕘)

## 📲 แจ้งเตือนบนมือถือ (Web Push)
- เปิด: หน้าภาพรวม → แบนเนอร์ "เปิดเลย" หรือ ระบบ → ฉัน → 📲 แจ้งเตือนบนเครื่องนี้ (ต้องล็อกอิน · เปิดแยกทีละเครื่อง)
- ค่าเริ่มต้น "ทุกเรื่อง" · กด 🔔/🔕 ที่ชื่อเรื่องเพื่อปิด/เปิดเฉพาะเรื่อง · หรือสลับเป็น "เฉพาะที่เลือก"
- iPhone: Safari → แชร์ → เพิ่มไปยังหน้าจอโฮม → เปิดจากไอคอน แล้วค่อยกดเปิดแจ้งเตือน (iOS 16.4+)
- ส่งโดย Cloudflare Cron ตัวเดิม (ช้ากว่า Discord ~5–10 นาที) · ไม่ต้องตั้ง Secret เพิ่ม — กุญแจ VAPID สร้างเองใน KV ครั้งแรก

## ความทนทาน
- อ่านเว็บพลาด → ลองใหม่รอบถัดไป (ทุก ~5 นาที) 3 ครั้ง
- ส่ง Discord พลาด → ส่งซ้ำเองอีก 3 ครั้ง (ห่างกัน 10 นาที ภายใน 24 ชม.)
- ออกหลายตอนพร้อมกัน → รวมเป็นข้อความเดียว “📦 ออกใหม่ 3 ตอน! (103–105)”
- สถานะเก็บใน branch `data` (เขียนทับ commit เดียว) → หน้าเว็บไม่ build ใหม่ทุกรอบ และ repo ไม่โตเรื่อย ๆ
- ⏳ หน้าเว็บนับถอยหลังวันหมดอายุ GitHub Token และบอทเตือนใน Discord ก่อนหมด 7 วัน
  วิธีต่ออายุ: GitHub → Settings → Developer settings → Fine-grained tokens → เลือก Token → **Regenerate** → วางแทน `GITHUB_TOKEN` ใน Cloudflare

## ติดตั้งครั้งแรก (ถ้ายังไม่เคยตั้ง Worker)

### 1. สร้างประตูหลังบ้านบน Cloudflare (ฟรี ~10 นาที)
1. สมัคร/ล็อกอิน https://dash.cloudflare.com
2. **สร้าง KV**: เมนู Storage & Databases → **Workers KV** → **Create instance** → ตั้งชื่อ `manga-watch` → Create
3. **สร้าง Worker**: เมนู **Workers & Pages** → **Create application** → **Start with Hello World!** → Get started
   → ตั้งชื่อ `manga-watch-api` → **Deploy**
4. **ใส่โค้ด**: กด **Edit code** → ลบโค้ดเดิมทั้งหมด → วางเนื้อหาไฟล์ `worker/worker.js` → กด **Deploy**
5. **ผูก KV**: เปิด Worker → แท็บ **Bindings** → **Add binding** → **KV namespace**
   → Variable name: `KV` (ตัวพิมพ์ใหญ่) → เลือก `manga-watch` → Add binding
6. **ตั้งค่า**: Worker → **Settings → Variables and Secrets → Add** ใส่ทีละตัว

   | ชื่อ | ชนิด | ค่า |
   |---|---|---|
   | `REPO` | Text | `HAKIRENz/manga-notifier` |
   | `OWNER_NAME` | Text | ชื่อล็อกอินของคุณ เช่น `boom` |
   | `ALLOWED_ORIGINS` | Text | `https://hakirenz.github.io` |
   | `GITHUB_TOKEN` | **Secret** | Token แบบ Fine-grained (Contents + Actions = Read and write เฉพาะ repo นี้) |
   | `OWNER_PASSWORD` | **Secret** | รหัสผ่านของคุณ (ตั้งใหม่ ยาว ๆ) |
   | `SESSION_SECRET` | **Secret** | ข้อความสุ่มยาว 32 ตัวขึ้นไป (พิมพ์มั่ว ๆ ยาว ๆ ได้เลย ไม่ต้องจำ) |

   กด **Deploy** / Save หลังใส่ครบ
7. ตั้ง Cron Trigger ทุก 5 นาที (ดูขั้น C ด้านบน)
8. คัดลอกที่อยู่ Worker (หน้า Worker จะมีลิงก์แบบ `https://manga-watch-api.ชื่อคุณ.workers.dev`)
   เปิดลิงก์นั้นในเบราว์เซอร์ ต้องเห็น `{"ok":true,"app":"manga-watch",...}` ถ้าเห็นข้อความ error จะบอกว่าตั้งค่าอะไรไม่ครบ

### 2. บอกหน้าเว็บให้รู้จัก Worker
1. ใน GitHub เปิดไฟล์ `config.json` → กดดินสอแก้ → ใส่ที่อยู่ Worker ในช่อง `worker_url`
   ```json
   "worker_url": "https://manga-watch-api.ชื่อคุณ.workers.dev",
   ```
   → Commit
2. รอ 1-2 นาที เปิดหน้าเว็บ กด Ctrl+F5 → กด **เข้าสู่ระบบ** → ใช้ `OWNER_NAME` + `OWNER_PASSWORD`
3. แท็บ **ระบบ** → กด **🔔 ส่งข้อความทดสอบ** ต้องมีข้อความเด้งใน Discord

## ยศ
| ยศ | ทำอะไรได้ |
|---|---|
| ไม่ล็อกอิน | เห็นแค่หน้าเข้าสู่ระบบ + ฟอร์มขอเพิ่มเรื่อง |
| สมาชิก | + กด 🔔 ติดตามเรื่องเพื่อให้บอทแท็กชื่อใน Discord |
| ผู้ดูแล | + เพิ่ม/แก้/ลบ/เปิดปิดเรื่อง, อนุมัติคำขอ, สั่งตรวจ, ส่งข้อความซ้ำ, ดูบันทึกการจัดการ |
| เจ้าของ (คุณ) | + สร้าง/ลบผู้ใช้ เปลี่ยนยศ รีเซ็ตรหัส, ตั้งสรุปประจำวัน, ทดสอบ Discord |

ผู้ดูแลไม่เห็น Token/Webhook และแก้โค้ดไม่ได้ ทุกการกระทำถูกบันทึกว่าใครทำ
เปลี่ยนยศหรือรีเซ็ตรหัส → เครื่องที่ล็อกอินอยู่ของคนนั้นจะถูกออกจากระบบทันที

## ฟีเจอร์หลัก
- **ติดตาม**: ปก, ตอนล่าสุด, ▲ ตอนก่อน→ตอนใหม่, อ่านถึงตอนไหน/ค้างกี่ตอน (จำแยกแต่ละเครื่อง), แถบ "อ่านต่อ", มุมมองรายการ/ตารางปก, ค้นหา (กด `/`), กรอง, เรียง
- **รายละเอียดเรื่อง**: ประวัติตอนใหม่, ความถี่การออกตอนเฉลี่ย, ตรวจล่าสุด/ครั้งถัดไป, ใครติดตาม, ข้อความ Discord ของเรื่องนั้น, เครื่องมือผู้ดูแล
- **เพิ่มเรื่อง**: วางลิงก์ → เห็นชื่อ ปก ตอนล่าสุด ก่อนกดเพิ่ม → ตรวจครั้งแรกให้ทันที
- **อัปเดต**: ข้อความทุกอันที่บอทส่งเข้า Discord หน้าตาแบบ Discord + สถานะส่งสำเร็จ/ล้มเหลว + แท็กใคร + ปุ่มส่งซ้ำ
- **ระบบ**: สถานะระบบ (เขียว/เหลือง/แดง), รอบตรวจล่าสุด, รอบถัดไป, เว็บที่มีปัญหา, โปรไฟล์ Discord ID, จัดการผู้ใช้, สรุปประจำวัน, บันทึกการจัดการ
- **แจ้งเตือน Discord**: ตอนใหม่ (แท็กเฉพาะคนที่ติดตามเรื่องนั้น), สรุปประจำวันตามเวลาที่ตั้ง, เตือนเมื่อเว็บมีปัญหา; ส่งพลาดจะลองใหม่ 3 ครั้งและจดไว้ให้กดส่งซ้ำ
- **แอปบนมือถือ**: เพิ่มไปหน้าจอโฮมได้, แจ้งเตือนบนเบราว์เซอร์ขณะเปิดหน้าไว้, ธีมสว่าง/มืด

## หมายเหตุ
- ถ้ายังไม่ได้ตั้ง Worker หน้าเว็บยังใช้ได้แบบดูอย่างเดียว
- repo เป็น Public: รายชื่อเรื่อง และ Discord User ID ของคนที่ใส่ไว้ (ใน `subs.json`/`notify_log.json`) ทุกคนเปิดดูได้ — Discord ID ไม่ใช่รหัสผ่าน แต่ถ้าไม่สบายใจ อย่าใส่
- ตรวจแบบสุภาพ: เว้นระยะ 4-10 วินาทีระหว่างคำขอเว็บเดียวกัน, ใช้ ETag, พักเมื่อเว็บตอบ 403/429 (1→24 ชม.) — ระบบไม่ปลอมตัวหลบ Cloudflare/captcha
- รองรับประมาณ 100-150 เรื่อง ถ้าเรื่องเดียวกันอยู่เว็บเดียวกันเยอะ ๆ (เกิน ~30 เรื่อง/เว็บ) ในโหมด ⭐ รอบหนึ่งอาจนานเกิน 5 นาที → ตั้งบางเรื่องเป็นโหมด ⏱ แทน
- แผนฟรีของ Cloudflare Workers: 100,000 คำขอ/วัน เหลือเฟือสำหรับกลุ่มเพื่อน
- อย่าแชร์ Token, Webhook, `OWNER_PASSWORD` และ `SESSION_SECRET` ให้ใคร
- เปลี่ยน `SESSION_SECRET` = ทุกคนถูกออกจากระบบ (ใช้เมื่อสงสัยว่าบัญชีรั่ว)
