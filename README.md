# ระบบแจ้งเตือนการ์ตูนอัปเดต (ฟรี 24 ชม.) — เวอร์ชัน 2

GitHub Actions ตรวจเว็บเป็นรอบ → ส่งแจ้งเตือนเข้า Discord → ดู/จัดการรายการผ่านหน้าเว็บ `index.html` (GitHub Pages)

## ตั้งค่าครั้งแรก
1. **Discord**: ตั้งค่าช่อง → Integrations → Webhooks → New Webhook → คัดลอก URL
2. **GitHub**: สร้าง repo (Public) แล้วอัปโหลดไฟล์ทั้งหมด (รวมโฟลเดอร์ `.github`)
3. Settings → Secrets and variables → Actions → New secret ชื่อ `DISCORD_WEBHOOK_URL`
4. Settings → Pages → Deploy from a branch → `main` / root
5. สร้าง Fine-grained token เฉพาะ repo นี้ สิทธิ์ **Contents** และ **Actions** = Read and write
6. เปิดหน้าเว็บ → ⚙ ตั้งค่า → วาง Token → บันทึก (จะขึ้น "👑 แอดมิน")

## อัปเดตจากเวอร์ชัน 1 เป็นเวอร์ชัน 2
อัปโหลดไฟล์ในโฟลเดอร์ update ทับของเดิมที่หน้า repo (Add file → Upload files แล้วลากไฟล์ทั้งหมดรวมโฟลเดอร์ `.github` ลงไป → Commit)
**อย่าอัปโหลดทับ `series.json` และ `state.json`** (รายการเรื่องและสถานะของคุณอยู่ในสองไฟล์นี้)
ถ้าลากโฟลเดอร์ `.github` ไม่ติด ให้ Add file → Create new file แล้วพิมพ์ path เต็ม เช่น `.github/ISSUE_TEMPLATE/add-series.yml` แล้ววางเนื้อหา

## สิ่งที่ใช้ได้ในหน้าเว็บ
- ปกเรื่อง ตอนล่าสุด และ "ตอนเก่า → ตอนใหม่" พร้อมประวัติการเปลี่ยนแปลง
- ป้าย "ใหม่" จนกว่าจะกดอ่าน (จำแยกตามเครื่อง/เบราว์เซอร์ของแต่ละคน)
- ค้นหา กรอง (ยังไม่อ่าน/มีปัญหา/ปิดอยู่) เรียงลำดับ ความเคลื่อนไหวล่าสุด
- ทุกปุ่มมีสถานะกำลังทำงาน + ข้อความเด้งบอกผลทันที เพิ่มเรื่องแล้วเห็นการ์ดขึ้นทันที
- ปุ่ม ↻ ตรวจรายเรื่อง, ตรวจทุกเรื่อง, ส่งข้อความทดสอบ Discord
- หน้าจะรีเฟรชเองทุก 1 นาที และเด้งเตือนถ้ามีตอนใหม่ระหว่างเปิดหน้าไว้

## ให้เพื่อนใช้งาน
- **เพื่อนแค่ดู**: ส่งลิงก์หน้าเว็บให้ ไม่ต้องมี Token เห็นรายการ ปก ตอนล่าสุด และกดอ่านได้เลย
- **เพื่อนขอเพิ่มเรื่อง**: เพิ่มชื่อ GitHub ของเพื่อนในไฟล์ `friends.txt` (หรือ ⚙ → เพื่อนที่ขอเพิ่มเรื่องได้) เพื่อนกรอกชื่อ+ลิงก์ในหน้าเว็บ กด "ส่งคำขอเพิ่มเรื่อง" → GitHub เปิดฟอร์มที่กรอกไว้ให้ → กด Submit → ระบบเพิ่มเรื่องให้เองใน 1-2 นาทีและตอบกลับใน Issue
- เพื่อนไม่ได้รับ Token และไม่ได้สิทธิ์แก้โค้ดหรือเห็น Webhook; คนที่ไม่อยู่ในรายชื่อจะถูกปฏิเสธอัตโนมัติ
- อย่าเพิ่มเพื่อนเป็น Collaborator ของ repo (จะได้สิทธิ์แก้โค้ด) ให้ใช้รายชื่อ friends.txt แทน

## หมายเหตุ
- ใช้ได้กับเว็บส่วนใหญ่โดยอ่านลิงก์ตอนในหน้าเรื่อง; MangaDex ใช้ API ตรง ๆ; ใส่ลิงก์ RSS ก็ได้
- เว็บที่ใช้ Cloudflare เข้มงวด/ต้องล็อกอิน/โหลดตอนด้วย JavaScript อาจอ่านไม่ได้ จะขึ้นข้อผิดพลาดในการ์ด
- ตรวจแบบสุภาพ: แต่ละเรื่องทุก 30 นาที เว้นระยะสุ่มระหว่างคำขอ ใช้ ETag และพักเมื่อเว็บตอบ 403/429 (1→24 ชม.)
- GitHub จะปิด schedule ถ้า repo เงียบ 60 วัน ระบบจึง commit สถานะวันละครั้งให้อัตโนมัติ
- ระบบไม่ปลอมตัวหลบ Cloudflare/captcha ถ้าเว็บไหนบล็อก ให้หา RSS, ใช้ MangaDex หรือรัน check.py บนคอมที่บ้านแทน
- อย่าแชร์ Token และ Webhook URL ให้ใคร
